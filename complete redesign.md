# HIREVIX NON-NEGOTIABLE DESIGN PRINCIPLES

The following rules are absolute and cannot be violated during redesign.

==================================================

Every screen must feel handcrafted.

Never allow any page to look unfinished.

Never create placeholder-looking layouts.

Never create generic AI-generated UI.

==================================================

Every page should immediately answer

Where am I?

What can I do here?

What should I do next?

The user should never feel lost.

==================================================

Every page must have

Clear hierarchy

Primary action

Secondary action

Helpful AI guidance

Progress indication

==================================================

Every module must naturally lead to another module.

The user journey should never end.

There should always be a meaningful next step.

==================================================

Never repeat the same layout more than twice.

Each module should have its own personality while remaining part of the same design language.

==================================================

All components should be reusable.

Buttons

Cards

Charts

Inputs

Dialogs

Tables

Timelines

Progress Indicators

Notifications

Everything must come from one unified design system.

==================================================

Do not overuse gradients.

Do not overuse glassmorphism.

Do not overuse animations.

Luxury comes from restraint.

==================================================

Whitespace is part of the design.

Never fill empty space unnecessarily.

Spacing should improve readability.

==================================================

Animations must communicate purpose.

Navigation

Feedback

Loading

Hierarchy

Progress

Success

Nothing should move without reason.

==================================================

The interface should always prioritize

Clarity

Speed

Trust

Professionalism

Accessibility

==================================================

Every AI response should feel

Human

Professional

Helpful

Actionable

Personalized

Never robotic.

==================================================

Every module should automatically use information from the Career Knowledge Graph.

Never ask users for information that already exists.

==================================================

Every page should maintain visual consistency through

Typography

Spacing

Icons

Motion

Color

Corner Radius

Elevation

Lighting

Interaction

==================================================

The product should feel expensive.

Not because of visual effects.

Because of attention to detail.

==================================================

FINAL GOAL

Create a platform that users remember.

Not because it is beautiful.

Because it makes career growth effortless.

Hirevix should become the operating system for a person's entire professional life.

When someone finishes using Hirevix, they should feel more confident, more prepared, and more employable than when they started.

The redesign should be globally competitive and capable of standing alongside the best AI SaaS products in the world.
